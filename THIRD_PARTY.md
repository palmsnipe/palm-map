- **PalmTLS 0.1.9**: [tagged source](https://github.com/palmsnipe/palm-tls/tree/v0.1.9), GPL-3.0-or-later. The app compiles the HTTP parser and uses the public PalmTLS system-library header from that tag. Map adds a response-header callback to the parser for tile cache directives and provider block notices. The app uses a separately installed ARM **Browser** or **TLS 1.2 compatibility** profile. The compatibility build adds SHA-384 and 4096-bit RSA verification and reuses the upstream ARM public RSA path; see `tools/build-palmtls-tls12.sh`. [wolfSSL source and Palm patches](https://github.com/palmsnipe/palm-tls/blob/v0.1.9/THIRD_PARTY.md) are identified by the PalmTLS project.
- **zlib 1.4**: ARM inflate sources have the [zlib license](vendor/zlib/LICENSE). See [upstream zlib](https://github.com/madler/zlib).
- **Palm Toolchain starter**: the minimal PACE startup and linker scaffold are adapted from the [Palm Toolchain example](https://github.com/palmsnipe/palm-toolchain) under the [MIT license](vendor/STARTER-MIT).
- **OpenStreetMap**: live Streets, Night and Shortbread map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL. The endpoints are subject to the [standard tile usage policy](https://operations.osmfoundation.org/policies/tiles/) and the [vector tile usage policy](https://operations.osmfoundation.org/policies/vector/). No public OSM tiles are redistributed in this project.
- **CyclOSM**: [cycling raster style](https://www.cyclosm.org/) built with data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL. Tiles are served by OpenStreetMap France under its [usage policy](https://www.openstreetmap.fr/usage/).
- **Natural Earth 5.1.2**: [country outlines](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) rendered as the included offline overview, [public domain](https://www.naturalearthdata.com/about/terms-of-use/).
- **GeoNames**: [cities15000](https://download.geonames.org/export/dump/) snapshot from November 17, 2026, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The app packages the ASCII name, country code and projected position, ordered by population.
- **CA certificates**: [GlobalSign Root R46 and GlobalSign Root CA R3](https://support.globalsign.com/ca-certificates/root-certificates/globalsign-root-certificates), and [ISRG Root X1 and X2](https://letsencrypt.org/certificates/), extracted from the Mozilla CA bundle distributed by Homebrew.
