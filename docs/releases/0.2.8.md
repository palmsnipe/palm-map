Map 0.2.8 is an OpenStreetMap viewer for ARM handhelds running Palm OS 5.
It supports fixed Graffiti areas and dynamic input areas.

Download `Map-0.2.8.zip` and install both `Map.prc` and
`PalmTLSArm-Modern.prc` via HotSync, a card, or CloudpilotEmu. Use one PalmTLS
profile at a time. The included PalmTLS 0.1.12 ARM Modern library provides
HTTPS with TLS 1.3 by default, without a separate entropy setup in Map.

- Streets opens by default. The Layers menu also offers Night, CyclOSM Cycle
  Map, Shortbread vector tiles, an offline Overview, and a custom raster layer.
- Shortbread draws angled street names, landmarks, city and water names, and
  provincial and national boundaries. Its settings control the map detail.
- Find searches cities and coordinates offline. Cached tiles stay available
  in offline mode, and the map shows how much tile data it has downloaded.

Live map loading was checked in CloudpilotEmu on a Tungsten E2 and Palm TX.
The install ZIP includes the license and third-party notices. The separate
source archive includes this Map revision, PalmTLS, and its pinned wolfSSL
source. `SHA256SUMS` lists the checksums for the downloads.
